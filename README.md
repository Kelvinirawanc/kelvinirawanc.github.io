## Deploy to GitHub Pages

1. Create or use the repository named **`kelvinirawanc.github.io`**.
2. Upload **the contents of this folder directly into the repository root**.
3. Confirm that `index.html` is visible at the top level of the repository.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Select **main** and **/ (root)**, then save.
7. Open **https://kelvinirawanc.github.io/**.

> Do not upload the ZIP itself as the website source. Extract the ZIP and upload `index.html`, `style.css`, `script.js`, `.nojekyll`, `README.md`, and the `assets` folder to the repository root.
